# Live tracker

`.scratch/<effort>/spec.md` is the live spec; issues live at `.scratch/<effort>/issues/NN-<slug>.md`. Durable records live in `docs/plans/`. Entries that have no effort directory yet live in the repo-root `TODO.md`. See `docs/agents/plan-docs.md`.

This directory is tracked. It travels into worktrees so an implementer sees the current spec and tickets.
