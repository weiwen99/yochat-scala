# 本地实例以独立窗口进程打开

<!-- tao:section decisions -->
## 设计决策

```{adr} 实例选择先锁定原窗口，再打开独立进程
:id: ADR_20261106_1CC2BTM4SMERY77X
:status: accepted

<!-- tao:field context -->
**背景与备选:** 同一设备可保存多个用户或同一用户的多个本地设备。恢复失败时，只有用户明确放弃本次恢复后，才可在另一目录另建身份，原目录仍须完整保留。直接替换进程内 Identity 或 Net 会让已排队的旧命令、网络结果及 Store 写者指向新实例，要求为所有既有入口重新建立跨实例认证。

<!-- tao:field decision -->
**选择:** 产品提供本机实例列表、新建实例和恢复失败后的另建入口。所有操作均先展示确认和保留原数据的说明，勾选同意后同步隐藏秘密、锁定原窗口，再以当前锁定会话代数准备一次性票据。票据固定有效五秒，启动时再次比较原实例及会话代数。原窗口保留，用户可返回并重新解锁。

每个进程的 Identity、Net、数据根与实例 ID 不可变。打开另一实例使用同一应用可执行文件的新进程，目标从锁态开始，创建或解锁均须走真实表单。实例 ID 只接受默认 ID 或随机生成的固定格式 ID，目录独占创建，不接受用户路径、不覆盖或删除旧目录；已有 Store 写者拒绝再次打开。实例数量最多 64，目录扫描最多 256 项，活动子进程最多 64。

父进程在五秒截止内接收本次 loopback 端点、随机 nonce、子 PID 和实例 ID 的完整启动记录，并发送确认字节；错 nonce、PID、实例、额外字节或迟到记录不能完成启动。未确认子进程在七秒内退出，包括父进程急退或确认连接提前关闭。普通启动没有该看门狗；已确认的独立窗口不依赖原窗口存活。错误仅回收本次未确认子进程，目录保留供重试。启动记录证明本次进程就绪，不是身份解锁或设备授权。

UI 的读列表与打开操作各有所有者。取消确认不启动进程；失败、固定截止到达、销毁或原窗口新认证会话使旧回复失效，旧回复不能恢复秘密或改写新会话界面。操作最多等待 27 秒，子进程停止最多等待两秒。生产系统凭据继续使用 YoChat 服务，E2E 构建只使用 YoChat E2E，测试清理不得删除生产条目。

<!-- tao:field consequences -->
**影响与后果:** 原实例的迟到 IPC 和网络只可能访问原进程的固定作用域。锁定关闭旧 Store；新实例的写者生命周期仍由稳定目录锁保护。实例列表只展示不含秘密的随机 ID，不解密身份资料。单纯切换操作系统焦点不属于产品实例选择操作；已经分别由用户解锁的两个独立窗口各自遵循空闲锁策略。

固定截止依赖操作系统按时调度线程和计时器，不保证整机暂停期间的墙钟退出。文件系统及进程创建由操作系统提供，失败不授权改动原目录。Quint检查安全和公平调度下结束性质；失败启动轨迹由Rust真实子进程拒绝路径与UI控制器共同消费，但这只是取消、锁定、失败及原数据保留的投影，不是完整原生产品旅程或所有调度等价证明。发布构建的多用户、同用户多设备及恢复放弃入口由真实原生验收承担，实际受检版本和范围见[主计划验证摘要](../../plans/2026-09/20260918-yochat-f2f-messenger.md#DOC_20260918_BFV4FCXTMM9MQRDD--verification)（{need}`UC_20260918_VX22BC4VKGYQ6MN2`、{need}`TASK_20261105_NJDK86BZVP0DHH4M`）。
```
