# 把一台设备作为常在线设备长期运行

<!-- tao:section scope -->
## 范围

说明怎样让本人的一台设备长期开着，在本人其他设备都离线时替本人接收消息
（{need}`REQ_20260918_GBC9KZAACYZ1RHYZ`）。当前由长期运行的桌面应用承担；无界面二进制的
依赖隔离不等于可部署的无人值守解锁方案。

**先读这一句：这台设备持有可解密的密钥材料。** 它能解开本人可见范围内的全部消息，拿到这台
机器、或者拿到它的数据目录与应用锁口令的人，就能读这些消息。因此只把它部署在你自己控制的
机器上——不要放在别人的电脑、共用机或托管环境里。

<!-- tao:section prerequisites -->
## 前提

- 这台设备已经是本人设备列表里的一台（用恢复短语加入，或由持有用户私钥的设备加进来）。
- 机器会长时间开机、不休眠，并且能上网。
- 你控制这台机器：只有你能登录，磁盘不对他人开放。

<!-- tao:section steps -->
## 步骤

1. 在这台设备上打开应用并解锁。应用解锁之后就自己起网络、收发消息，不需要另外开启什么。
2. 在设置的「设备」一栏确认那段说明：这台设备持有可解密你可见范围内全部消息的密钥材料。
3. 让应用保持运行。macOS 14及以后已禁用WebView后台节流，窗口可以最小化；旧版macOS
   和其他平台尚无同等后台执行验证。机器休眠时应用收不到东西。
4. 应用锁定后不再解密与落盘，直到再次解锁；后台收消息、同步或重试不会重置用户空闲
   计时，因此不能靠持续流量保持解锁。长期运行不应以削弱应用锁替代机器的物理安全
   （{need}`TASK_20260919_80NB4PK0KR53XJVS`、{need}`TASK_20260919_CNDAGMZJP5S3CJ6R`）。
5. 其他设备上线后，经本人设备之间的同步取得这台设备在它们离线期间收下的消息。

<!-- tao:section troubleshooting -->
## 排查

- **其他设备上线后没拿到消息**：确认常在线设备当时已解锁，来源设备仍持有内容、目标设备
  仍获授权且实际完成了本人设备同步；“窗口开着”或“设备已列入名单”不等于密码会话已就绪。
- **收不到任何消息**：在设置的「中转与发现」里看此刻在用的是哪一种；选了「都不用」时，隔着
  NAT 的设备多半连不上。
- **改中转设置后仍连不上**：区分“已保存”和“此刻在用”；设置在重启应用后生效。自建
  pkarr服务必须同时支持发布与查询，只有发布接口的服务不足以发现对端
  （{need}`TASK_20260924_823S0AQ3VBRQC778`）。
- **要查日志**：日志在应用数据目录`logs/`，各实例独立；`YOCHAT_LOG`默认`warn`。
  密钥和恢复短语不应写入日志，但debug/trace诊断可能包含设备标识，发送前自行核对。
  日志检索未命中有限编码的密钥样本，不等于证明所有序列化棘轮私料、任意崩溃转储
  都无泄漏；线程panic也不等于整进程退出（{need}`TASK_20260919_80NB4PK0KR53XJVS`）。
