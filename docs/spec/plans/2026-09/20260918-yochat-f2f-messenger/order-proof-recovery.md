# 缺失排序元数据的有界补证

<!-- tao:section overview -->
## 概述

[统一排序](ordering-and-attention.md#DOC_20261103_VE1ZM1QD1QP5NK51--architecture)和[正文事务](order-content-and-conflicts.md#DOC_20261103_9C7EMXGVZB2RXQA8--contracts)规定原始签名及缺前置暂存；本设计定义补证所有者、权限和退出路径。新设备收到加入后的新消息时，自动补齐验证排序所需的元数据，不自动索取加入前正文或秘密。模型任务{need}`TASK_20261103_NYBT3W5C273W3JVF`先于运行时{need}`TASK_20261103_TY9SPKDC1FJ0CQEX`，普通收发接线依赖后者；用户批准的历史复制复用此服务。实际结果由[计划验证摘要](../20260918-yochat-f2f-messenger.md#DOC_20260918_BFV4FCXTMM9MQRDD--verification)维护。

<!-- tao:section architecture -->
## 边界与架构

复用现有设备到设备X3DH恢复通道，不占聊天/密码日志位置，不把业务证据错误当密码组故障。每次请求绑定会话、当前授权代次、源/目标设备、持久单调尝试序号、随机128位任务标识及请求根哈希摘要。请求代次属于请求方，不能与源设备本机代次直接比较；源另存自己的本地代次来废弃旧回调，两端权限变化可以独立发生。已关闭/取消/过期尝试不能被迟到响应重新打开；新尝试用新标识；源保存每个请求方/会话的最高尝试序号，旧尝试不能以更高恢复计数重新开工。每会话/来源只保留一个活动请求，其他待验证正文合并排队，不无界创建网络任务。

源必须已完整验证请求根及其闭包；冻结根集合及最高逻辑高度，按（已验证高度、证书哈希）分页传输该高度以内的无正文证据。原始已验证闭包意味着后加低高度的无关证据不影响初始根的祖先。游标只来自已提交页，不由“本机已知消息数”猜测；续传仅复用同源、同根、同截点的提交游标。源缺根明确返回不可用，目标保留正文但不伪造顺序。

<!-- tao:section contracts -->
## 数据与权限

请求最多1024根，页最多32证书且完整编码不超过512 KiB，在途最多4页。回复只含原证书和必要的原始根签设备批次，不含正文、正文/引用秘密、历史原件或已查看状态。设备自签条目只证明持钥，不能替代用户根签授权；根必须是本会话的本人或对端用户。历史绑定验证不覆盖当前设备名单、吊销或联系人状态；历史密钥签出的元数据不声称具有可信创建时间。身份分叉继续按既定规则隔离，不根据自称时间选择赢家。

源、目标及会话每次收包均按当前权限重查；请求与ACK精确绑定所有者、页、内容摘要和游标。目标只原子提交当前期待的页，成功ACK在该页事务提交后发出；已提交重复页只能重复确认，不能重插前沿。恢复通道的全局计数与业务页所有权分开：较新的无关控制包不能使仍属于活动补证的合法旧计数页/ACK被丢弃；接受页和推进单调全局最大值同事务。未知/迟到任务不借高计数改变业务进度。

QUIC并行流不保证页的到达顺序。目标在当前期待页之后的四页窗口内，按精确租期暂存最多三个未来页及各自最初的恢复计数；暂存前核对当前所有者、权限、固定截止及页编码上限，不提交证书、消耗计数、确认成功或延长期限。相同重复页不替换冻结计数，内容冲突及窗口外页拒绝。缺页提交后逐页重新执行原有原子校验，逐页确认，再取连续暂存页；后页失败不撤销或丢失先前已经提交的确认。暂存仅属当前Store的易失所有者，取消、换主、吊销、过期或重启不能把旧页带入新租期。否则每个合法乱序窗口都会额外等待30秒重传，即使未丢包也可能耗尽固定总截止。

每页原子校验原作者签名、双方用户下的正向根签历史绑定、父闭包、高度、当前授权、固定总截止和剩余存储预算，再提交证据、游标/摘要回执及可见性修订。无效页整笔回滚，不部分推进时钟。证据与根签见证按实际保留字节计量并去重，不绕过原资源上限；额度不足明确结束本次尝试，正文仍待验证。

## 有界性与正确性

双方分别从本地开始/首次接纳起使用固定150秒总截止，单页重试间隔30秒、最多5次，进展和重复请求均不续期；源迟收请求可能晚于目标关闭，目标仍拒绝旧响应。SQL每次固定五秒执行预算，不在事务内等待网络。重启结束旧尝试，保留已提交证据及续传位置，新尝试重新分配所有者；不把持久墙钟回拨当作续延旧尝试的理由。剩余尝试预算持久保留，真实新连通事件才按既定规则开启新纪元。

补证生产者须在领取请求/页的发送尝试前核对当前所有者、授权和原截止，再确认对端长期预密钥可用；身份记录、备用或保留的一次性包均不能替代恢复材料。缺包或包已过期时保留当前工作，经既有认证公告交换及按设备共享的节流补包，不分配数据页、重试次数或恢复计数，不把合法入站请求变成内部错误。补包后仅在原租期仍有效时继续；始终无包也按原固定截止结束，迟到公告不复活已退休的尝试。

Quint使用两次尝试、两页、有限0..6时钟，每次固定两tick、每页两次发送、两单位存储预算的缩小投影；另以五个候选页/四个槽验证窗口和两次发送预算，窗口函数不拥有等待，截止由前述模型覆盖；恢复计数按旧/新比较关系缩小，分配器唯一单调另由Rust核对。时钟和结束回调需公平调度，无网络必达承诺。检查元数据不带正文、根签/用户范围、页原子性、合法旧计数、固定截止、取消/重启、迟到所有者、重复ACK与发送预算；实际Rust映射150秒/30秒/5次/4页，并用真实密码/SQL逐状态对照。已有orderLifecycleChecks继续验证，不以模型有限投影代替真实接线。

未来页暂存另有所有者／截止安全投影及五页／四槽的无丢包乱序进展投影。健康进展假设本地校验成功，发送、到达与连续提交公平调度且在下一次截止时钟机会前完成；不承诺任意网络延迟下必达。丢弃未来页、提前确认暂存页和旧暂存跨所有者均有独立错误变体。Rust的六页边界回归使用161条证书，在每批逆序到达时验证全部证据、最终真实确认及无需额外重传，不增加原窗口或截止。

## 失败与恢复

失败、取消、存储不足和重启均结束旧活动请求，已提交证据不回滚；部分网络输入不推进确认时钟。尚缺元数据的正文不进入确定列表，不显示成已完成导入。源重启后旧出站回调不能恢复已结束的源任务；目标仍可在自己的有效请求内接纳之前已发出的合法包，不因此重开源任务。

首次发布等待绑定所选授权设备的完整本地前沿，不是对离线或并发设备的全局屏障。所选设备失去当前权限时，可改选本会话仍获授权的设备；没有合法替代者则继续等待。授权仍有效的设备不因周期轮询而被替换。改选与关闭旧来源任务同事务提交，并以新来源已有的最大尝试序号作为下界；改选前发出的请求可以贡献有效元数据，但不能解除新的等待。失败不改变数据库或内存所有者，不重置尝试预算；已经完成的合法检查点也不因来源后来被撤销而丢失。

当前传输单帧1 MiB上限保持。补证采用有标识、精确长度的当前二进制编码；用途前缀仅作不可信分类，未知家族版本由本解析器拒绝，不回退其他用途。恢复密文字段显式容纳合法页及封装。历史复制同样采用当前二进制记录，避免JSON转义/十六进制放大拒绝最大合法正文、引用和证据；保留40KB普通打包目标及既有窗口/重试预算，不加入旧格式回退。编码成功不等于作者授权、父闭包或页所有权验证成功。{need}`TASK_20261103_TY9SPKDC1FJ0CQEX`和{need}`TASK_20261103_NKV98TSQMB3ZTZZX`承接。

## 验证

先正向安全/条件结束及错误变体，再导出覆盖正常、页乱序/重复、旧计数、失败、取消、重启和迟到的轨迹；运行时真实SQL/计数账本及X3DH回放，不用模拟开关代替。新设备只得到加入后正文而能验证当前顺序；正常消息与经用户批准的历史复制都覆盖。最大页/证书/根签见证组合实际经过1 MiB传输边界验证，未知格式拒绝。性能阶段保持在全部正确性验收之后。
