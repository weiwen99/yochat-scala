# 统一测试入口与分层全量检查

<!-- tao:section scope -->
## 范围与通过含义

用户要求按section整理justfile、补充注释、合并不必要的独立入口，并新增fullcheck和fastcheck。输入为main上的`7aadcdfedc173d0942364312f27ea09186c71a5f`，在`chore/test-entrypoints`中维护，不推送。此前依赖升级的历史结果不改写为本次新入口通过。

用户针对本次问题明确选择：fullcheck运行当前平台适用的全部自动测试，包含ignored压力测试与全部适用GUI专项；其他平台与人工验收明确列为不适用或未覆盖，不冒充执行成功。适用项缺工具、权限、有效程序或其他前置条件必须失败。fastcheck只运行重要、短耗时的自动检查，不加入完整性质求解、Rust长流程、压力或GUI批次。

不安装工具、不自动授权、不绕过冻结程序的干净提交和哈希检查，不放宽产品/模型边界与既有单项截止。真实系统通知点击与输入法组合操作不能由自动回执冒充；读取现场的历史诊断需要调用者提供原件，不作为无参数自动测试伪造输入。

用户随后要求分析耗时、优化并行度与测试缓存，但不能损害正确性；该要求优先于继续旧串行批次。只有完整输入匹配的确定性模型成功结果可复用，报告须区分缓存与本次执行，其他动态验收仍实际运行；提供明确冷运行入口。

## 分类与执行约束

Just以section注释和可发现分组组织聚合、源码/工具、Rust/依赖、界面、模型、原生及人工/诊断入口。可共享前置条件与失败语义的短检查合并；证明、压力及GUI仍保留可定向调用的边界。命令、超时和fast/full选择由唯一执行清单维护，Just负责稳定用户入口，不维护第二份测试命令。

所有进程由既有owned_process管理，失败后收集后续独立结果；所有权清理无法证明时立即停止，不继续可能共享端口/数据库的工作。普通错误、超时、不适用与真正人工观察分别报告。GUI共享桌面与数据，必须串行，使用既有冻结、签名、精确进程和清理工具；不同配置中的自动场景须实际展开，不只执行默认grep的一部分。

CI保留跨平台无GUI检查、独立Kani及打包的真实边界；CI子集必须明确命名，不能以环境变量悄悄缩小fullcheck。全量并不代表任意宿主可证明其他操作系统或人工场景。

加速以实际测量为依据：主线程有界进程调度，命令各有独立截止控制器，共享Cargo/UI产物互斥，性能/真实协议/GUI/证明阶段独占。模型纯类型可并行，性质工作进程各自拥有独立端口、输出和临时目录的后端，按CPU与内存限额分配TLC工作线程，不共享默认Apalache服务，不改变原性质、论域、步数或3600秒整批截止。仅以完整输入/配置/工具指纹匹配的成功判词复用模型；失败、超时、未完成、输入变化、损坏回执和清理不明均不可发布。保留`--jobs 1 --no-cache`冷运行路径；不缓存实际Rust、网络、GUI或压力结果。

验证范围沿用[三层验证策略](../../engineering/decisions/verification-strategy.md)，不把编排成功替代模型、真实实现或人工验收的结论。

2026-11-14首次`just fastcheck`实际86.494秒，31项中27通过、4未通过，非零返回：生成的vendor源码残缺、设计断言仅查询旧任务附件、文档指纹过期，并导致依赖格式项阻塞。已按固定发布包/补丁重建vendor，原iroh残余两文件保留在忽略目录`.local/vendor-incomplete-iroh-20261114-111055/`，保留加密库原Cargo缓存；断言守卫现读取真实计划任务定义；经核对协议语义未变后更新53个模型covers及相关清单指纹，没有增加基线债务或改变模型性质。

修复后实际`just fastcheck`退出0，87.917秒，32项全部通过，含新增编排/任务归属/原生/离线回归及既有进程所有权回归；文档结构校验通过。`just --list/--groups`已实际观察分类；原生普通/人工参数化列表均可调用。macOS直接`just kani`和缺现场的`just history-diagnose frame`均以2退出，没有静默通过。当时尚未完成fullcheck；后续当前输入的整批结果见下，不能用该次短检查替代。
