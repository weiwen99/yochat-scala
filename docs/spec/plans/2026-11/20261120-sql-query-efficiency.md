<!-- tao:section design -->
## 约束

优先使用已有主键、准确的结构化条件和有依据的索引；不能用强制索引掩盖大范围扫描，也不能用庞大BLOB索引代替调用链中已有的定位信息。修正保持原件精确比较、当前授权、删除、事务原子性和固定预算；新增索引同时评估存储、写入及迁移成本。

所有无索引全表扫描必须登记并处理。对于全量导出、迁移或清理等确实需要遍历全部数据的语义场景，单独列明原因与替代方案，提交用户决定；不得自行豁免或把未获确认的扫描标为通过。
