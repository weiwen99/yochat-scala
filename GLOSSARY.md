# YoChat

Serverless, end-to-end-encrypted friend-to-friend messenger. This glossary defines the product vocabulary; implementation terms belong in the code. Terms migrate from `docs/spec/glossary.md` as they are used.

## Identity

**用户**:
A person in YoChat, represented by a locally generated user key pair; there is no registration.
_Avoid_: 账号, 身份

**设备**:
One machine of a user. Every device holds its own device key pair and the user's public key; holding the user private key is optional.
_Avoid_: 客户端, 节点

**设备列表**:
The versioned set of a user's current devices, signed by the user private key and synced to contacts.
_Avoid_: 设备清单

**设备吊销**:
A signed statement by a device holding the user private key that a device public key is no longer accepted. The user public key and safety number do not change.
_Avoid_: 删除设备

**恢复短语**:
The writable form of a user private key. v1 does not implement recovery; the term is kept for later plans.
_Avoid_: 助记词, 种子

## Relationships

**联系人**:
Another user with whom a two-way relationship has been established by an invitation and a reply, each confirmed on its own device.
_Avoid_: 好友, 朋友

**邀请**:
A text generated by a user, signed by the user private key, carrying the user public key, a device public key, a channel identity, an expiry, and an ephemeral public key that also serves as the invitation id.
_Avoid_: 邀请码, 二维码

**邀请应答**:
A reply to an invitation, signed by the replying user's private key and encrypted to the invitation's ephemeral public key. Only the inviter can open it.
_Avoid_: 接受邀请

**安全码**:
A value both sides can compare out of band to detect a man-in-the-middle at relationship setup. It is derived from the two user public keys; knowing it proves nothing by itself.
_Avoid_: 指纹, 校验码

**渠道身份**:
The pair of a channel label and the user's authoritative account on that channel. It is local private data, synced between the user's devices, and enters an invitation or reply only when the user chooses it.
_Avoid_: 账号绑定

## Conversation

**聊天会话**:
The ordered sequence of all messages between the user and one contact, or between the user and themself. It is the only place those messages exist.
_Avoid_: 会话, 对话

**应用会话**:
The period from one unlock to the next lock. Locking is a security boundary, not a UI transition; the next person to unlock may be someone else.
_Avoid_: 会话

**常在线设备**:
One of the user's own always-on, unlocked devices that can receive while the user's other devices are offline. It holds the keys for the messages it can see; it is not a ciphertext-only relay.
_Avoid_: 个人节点, 服务器

**等待**:
The state in which a message has not arrived and later messages are therefore not shown yet. It is caused by reordering, ends when the missing message arrives, and must not be presented as a problem the user has to fix.
_Avoid_: 停滞

**重发**:
Sending a message that was already sent once. It is triggered by the receiver after a missing-message timeout, or by the sender when no delivery confirmation arrives; both are automatic.
_Avoid_: 重试, 补发

**通道重建**:
The receiver-initiated, automatic re-establishment of the encrypted channel and retransmission of unconfirmed messages when the receiver cannot decrypt the sender's messages.
_Avoid_: 重新加密, 重新握手

## Network

**中转**:
A third-party facility that forwards bytes when two devices cannot connect directly. It can see device endpoints, timing, byte/frame counts, local addresses, and the relay protocol version; content remains end-to-end protected.
_Avoid_: 服务器, 代理

**直接连接**:
A connection between two devices that does not pass through a relay. It has one fewer observer than a relayed connection, at the cost of revealing the local public address to the peer.
_Avoid_: P2P 连接
